Conversor de Moedas

Este projeto foi desenvolvido com o objetivo de praticar e aprimorar meus conhecimentos em HTML, CSS e JavaScript, criando uma aplicação simples, intuitiva e funcional para conversão de moedas.
Durante o desenvolvimento, pude treinar bastante lógica de programação, manipulação do DOM e integração com dados dinâmicos, além de reforçar boas práticas de organização de código.

Funcionalidades

-Conversão entre diferentes moedas em tempo real

-Interface simples e amigável

-Atualização automática dos valores convertidos

-Validação básica de entrada

-Layout responsivo


🚀 Tecnologias Utilizadas

HTML5 — estrutura da página

CSS3 — estilização, layout e responsividade

JavaScript — lógica da aplicação e manipulação dos valores



🛠  O que aprendi com este projeto

Melhor compreensão da lógica por trás de cálculos dinâmicos

Prática com eventos em JavaScript

Uso eficiente de querySelector, funções e condicionais

Organização de código para melhorar legibilidade
